# PAY-024 / MT-004 — odmowa, anulowanie i niepewny wynik

- Data: 16 października 2026 r.; środowisko: lokalne, commit bazowy `4ed0482` z zachowanymi zmianami PAY-023. Publiczny checkout nadal wyłączony.
- Testy automatyczne: **Pass, 11/11** w 2 zestawach (`pnpm --filter api test -- pay024-payment-outcomes.spec.ts listing-payment-reconciliation.service.spec.ts`). Sprawdzono timeout → `unknown`, blokadę ponownego zapisania wyniku POST, definitywną odmowę, niezgodną kwotę/ID, spóźniony zweryfikowany sukces, powtórzone potwierdzenie, stary status odmowy, wygaśnięcie próby i odtworzenie rekoncyliacji po restarcie. Testy użyły mocka operatora i lokalnych obiektów; nie kontaktowały się z Tpay ani z bazą roboczą. Pierwszy przebieg istniejącego testu rekoncyliacji wymagał aktualizacji oczekiwanej kolejności blokad; po poprawce oba zestawy przeszły.
- MT-004 — przerwanie płatności przed zatwierdzeniem: **Blocked**. Publiczne endpointy nadal zwracają `PAYMENTS_UNAVAILABLE`; lokalny web nie był dostępny pod `localhost:3000`. Wcześniej strona płatności Tpay Sandbox zwróciła HTTP 403. Nie było bezpiecznej ścieżki do przerwania aktywnego checkoutu. Nie utworzono kolejnej transakcji, nie użyto karty ani pieniędzy.
- Dane i zachowanie: brak migracji i zmian w roboczej bazie. Zweryfikowany status operatora musi pasować do lokalnej kwoty, waluty, transakcji, zamówienia i próby. Potwierdzenie zapisuje płatność, zamówienie i uprawnienie w jednej transakcji; odmowa nie nadaje uprawnienia. Stan `unknown` pozostaje do uzgodnienia i nie powoduje drugiego POST. Powrót z anulowania nadal sam nie zmienia danych serwera.
- Ograniczenie: `PAYMENT_GATEWAY` nie jest obecnie podłączony do publicznego checkoutu ani domyślnie wstrzyknięty do rekoncyliacji. Bez niego rekord `unknown` jest raportowany jako nierozstrzygnięty; nie ma automatycznego odczytu Tpay. Niepewny POST bez otrzymanego ID transakcji wymaga osobnego uzgodnienia z operatorem. Definitywna odmowa POST zapisuje lokalne `Payment.failed`; projekcja statusu starego zamówienia wymaga wywołania ścieżki rozliczającej próbę, która w publicznym checkoutcie pozostaje wyłączona.
- PAY-023: pełny powrót z Tpay i kontrola lokalnego UI nadal **Blocked** zgodnie z [protokołem PAY-023](2026-10-16-pay-023-local.md). Nie uznajemy tych kontroli za zaliczone.

Manual regression required: MT-004, MT-016.
